## 等级规则

词库采用累计式等级：

- 400分：读取编号1–400
- 600分：读取编号1–750
- 700分：后续扩展至编号1000

| 字段 | 说明 |
|---|---|
| id | 连续编号 |
| word | 英文单词 |
