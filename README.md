- 已包含：英文单词、美式IPA候选音标、词性、中文核心释义、等级、主题
- 例句和例句翻译：下一轮补充

## 等级规则

词库采用累计式等级：

- 400分：`level <= 400`
- 600分：`level <= 600`
- 700分：`level <= 700`

- 编号范围：1–400
